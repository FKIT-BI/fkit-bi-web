# WEB-006 / WEB-007 — словари, справка и автокоды

Спецификация: `fkit-bi-infra/docs/bmad/implementation-artifacts/spec-web-onboarding-wizard.md` (разделы 6–8).

## Scope

**WEB-006. Словари и справка.**
- `src/shared/i18n/dictionaries.ts` — русские подписи и пояснения для перечислений API. Словари закрытых enum типизированы
  `Record<Enum, …>`: новое значение в API без перевода не соберётся. `fieldLabel(path)` переводит `fieldErrors[].path`
  в подпись поля («parameters[0].unitCode» → «Параметры № 1 → Единица измерения»).
- `src/shared/ui/form.tsx` — `EnumSelect`, `HintLabel` (ⓘ), `DurationInput`, `HelpDrawer` (кнопка «Справка» в админке).
- Убраны сырые коды: статусы («Активно», «В мониторинге» / «Не подключена»), формат и характер сигнала, «что измеряет»,
  вид узла (сгруппирован), состояния по умолчанию, часовые пояса, единицы (символ вместо кода), коды ошибок в заголовках
  (сценарии, запуски), CSV текущих значений (свежесть, качество). Компоненты переименованы в «узлы машины».
- Длительности (`*Ms`) вводятся в секундах/минутах/часах.

**WEB-007. Автокоды.**
- `src/shared/lib/code.ts` — `makeCode(name, prefix, taken)`: транслитерация (ГОСТ 7.79 Б, упрощённо), `A–Z0–9_`,
  префикс при старте не с буквы, ≤ 64 символов, суффикс `_2`, `_3` при совпадении с уже загруженными кодами.
- `useAutoCode` + `CodeField`: код свёрнут в строку «Код: X — создаётся из названия · Изменить код»; у созданного
  объекта только для чтения. Формы: предприятие, смена, причина потерь, линия, машина, узел, сигнал, параметры машины,
  сценарий генерации (пустой код → из названия), старый «Мастер настройки» (код необязателен).
- Исправлено: в старом мастере `customSemanticCode` больше не `CUSTOM_VALUE`, а строится из названия сигнала.
