# WEB-002 — синхронизация с API бэкенда и переключение хостов

Status: implemented locally.

- Контракт: `openapi/analytics-api.yaml`, `openapi/generator-api.yaml` (с bi.kitexp.ru), типы — openapi-typescript,
  клиент — openapi-fetch с Bearer-авторизацией; собственный черновой `openapi.yaml` удалён.
- Вход через `/auth/login`, токен в sessionStorage, защита маршрутов, выход.
- Моки переписаны под реальные пути `/api/analytics/api/v1/...` и схемы; контрактный тест валидирует ответы Ajv по спеке.
- Виджеты переведены на реальные модели: operations read models, AnalyticsSummary/Metrics, LossTimeseries/LossPareto,
  ChronometryResponse, StateIntervalPage (курсоры), ManualIncident (причина и/или переопределение состояния).
- Хосты: `npm run dev` (mock), `dev:local` (localhost:8080/8081), `dev:stand` (api/generator.bi.kitexp.ru);
  в контейнере `ANALYTICS_API_URL` / `GENERATOR_API_URL`.
- Проверки: typecheck, lint, 41 тест, build (mock и real).

Замечания к спеке бэкенда:
- `Enterprise`, `StateRule` построены через `allOf` с базой `additionalProperties: false`
  (`EnterpriseCreate`, `StateRuleInput`) — по строгому JSON Schema такие ответы невалидны; в тесте ограничение снято.
- `servers: ../api/v1` относительно `/api/analytics/openapi/` даёт `/api/analytics/api/v1` — клиент в develop
  (`/api/analytics/v1`) обращается не туда.
